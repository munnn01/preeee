# V6 H.265 source-disjoint holdout result package

The frozen V6 H.265 policy was evaluated once on 1,000 new Kinetics-400 source IDs in two 500-source Kaggle shards. The prespecified H.265 gate **fails**: BD-rate Top-1 versus identity is −13.62% for `r2plus1d_18` and −11.11% for `r3d_18`, both above the strict −15% threshold. Direct V6 versus V2-C BD-rate on `mc3_18` is +1.53% (95% CI −0.49% to +3.32%), so improvement of the third analyzer is not established. V6 H.264 was not evaluated. See the [full report](../../docs/RESULTS_HOLDOUT_V6.md) and [merged JSON](h265_result.json) for all curves, comparisons and intervals.

The merged JSON has SHA-256 `69d387c2c8fd7c6286228eda3bde211f32e9ca58ae82104dec41c7cb2654fdad`; it was recomputed independently from the same committed source records and matched byte for byte. BD-rate and percentile 95% CI were computed after merging both shards; bootstrap used 2,000 paired draws of whole source videos, seed `20261001`.

The `raw/h265/shard_{0,1}/{primary,mc3}/` directories contain unchanged manifest and source-level JSONL records extracted from the two completed Kaggle archives. [archive_manifest.json](archive_manifest.json) records the original archive sizes and SHA-256 values; the archives themselves are retained as notebook outputs, not duplicated in this Git package. [run_provenance.json](run_provenance.json) binds raw record hashes, source/index/freeze fingerprints, model hashes, seed, Kaggle notebooks and commits. [SHA256SUMS.txt](SHA256SUMS.txt) covers the package files except itself.

The protocol was first committed at `385674ddf93d477d78f0b6b1b4abdff667eee7e5`; source IDs and video byte hashes at `dd3f5a14708ca37a9db537d17ca23638a4dfc855` before reading labels; labeled index and analysis code at `de9d37866216649e978b263a3af1ad4ab9e5d6e7` before running analyzers. The sample is source-ID-disjoint from audited development and previous holdouts within Kinetics-400, not an external-domain dataset. The frozen [preregistration](../../docs/PREREGISTRATION_V6_HOLDOUT.md) and [split audit](../../docs/HOLDOUT_SPLIT_V6.md) retain their premeasurement status text to preserve the original lock.

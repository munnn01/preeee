# Literature audit for the V8 CAL motion-protection pilot

| Primary source | Established result or method | Relation to this pilot |
|---|---|---|
| [Lu et al., *Preprocessing Enhanced Image Compression for Machine Vision* (2022)](https://arxiv.org/abs/2206.05650) | A neural preprocessor precedes a conventional, non-differentiable image codec and aims to retain task-relevant information. | Prior art for the broad pre-codec concept. This pilot tests a fixed video motion mask, not a new claim to the concept. |
| [Zhao et al., *A Preprocessing Framework for Video Machine Vision under Compression* (DCC 2024; preprint posted 2025)](https://arxiv.org/abs/2512.15331) | Neural video preprocessing with a virtual codec for training and standard codecs for testing. | Direct video pre-codec prior art. Our fixed, label-free mask differs in implementation but superiority is an empirical question. |
| [Wu et al., *Compressed Video Action Recognition* (CVPR 2018)](https://openaccess.thecvf.com/content_cvpr_2018/papers/Wu_Compressed_Video_Action_CVPR_2018_paper.pdf) | Action recognition can use compressed-stream motion vectors and residuals as useful temporal information. | Motivates protecting motion, although their classifier input and training differ from our frozen RGB analyzers. |
| [Shou et al., *DMC-Net* (CVPR 2019)](https://openaccess.thecvf.com/content_CVPR_2019/papers/Shou_DMC-Net_Generating_Discriminative_Motion_Cues_for_Fast_Compressed_Video_Action_CVPR_2019_paper.pdf) | Discriminative motion cues from motion vectors and residuals help compressed-domain action recognition. | Supports the motion hypothesis, but it does not establish that our mask improves BD-rate. |
| [Gadot et al., *RL-RC-DoT* (CVPR 2025)](https://openaccess.thecvf.com/content/CVPR2025/papers/Gadot_RL-RC-DoT_A_Block-level_RL_agent_for_Task-Aware_Video_Compression_CVPR_2025_paper.pdf) | Task-aware standard-encoder control allocates bits by region via block-level QP decisions, evaluated on detection and ROI encoding. | Region prioritization is prior art. This pilot changes pixels before a fixed encoder and tests action recognition; it does not claim comparable performance. |

The cited papers motivate a falsifiable choice: retain high-motion pixel regions while smoothing quieter areas before H.265. They do not imply a numerical gain for this dataset or these analyzers. The experiment and limitations are fixed in [PREREGISTRATION_V8_MOTION_PILOT.md](PREREGISTRATION_V8_MOTION_PILOT.md).

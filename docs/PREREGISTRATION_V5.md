## Question and fixed candidate

Can a simple, label-free **prediction agreement guard** retain approximately the V2-C bitrate benefit on both primary analyzers while reducing same-QP correctness losses? V5 uses the six existing codec candidates, five QPs `30,35,40,45,50`, H.264/H.265, and the four frozen V4 probability models recorded in `configs/v4_frozen/manifest.json`. There is **no new model fitting, feature engineering, candidate transform, codec parameter, or analyzer** in this run. The baseline comparators are identity, frozen V2-C, and frozen V4.

For a candidate to be eligible, it must: (1) have lower bpp than identity; (2) have `anchor_top1_agrees == true` for **both** `r2plus1d_18` and `r3d_18`, using only label-free primary-analyzer signals; and (3) satisfy the same two predicted correctness-delta inequalities as V4. Identity is always eligible. Select the eligible candidate with the lowest bpp, breaking ties by the original six-candidate order. A candidate's correctness fields, label, source ID, `mc3_18`, and any holdout value are inaccessible to the selection function. The agreement guard is fixed here and is **not** selected from a guard/no-guard grid.

Report full curves, V5 versus identity/V2-C/V4 direct paired BD-rate and BD-accuracy, all same-QP gaps, choices, and percentile 95% intervals from **2,000 paired source-video bootstrap draws**, seed `20260929`. All QPs, arms, codecs, and the two primary analyzers remain paired by source. Do not average shard BD-rates or alter `src/metrics/bd_rate.py`/bootstrap. The DEV readout is developmental, not confirmatory.

A codec is eligible for any later holdout proposal only if on DEV both primary BD-rates versus identity are ≤ V2-C plus **1.00 percentage point**, both BD-accuracies are >0, and both minimum same-QP gaps are ≥−1.00 percentage point. This rule does **not** change the original confirmatory gate, which remains at least one codec with both primary BD-rate Top-1 point estimates **<−15%** and BD-accuracy >0.
